# pipehex

Pipe CSV/TSV hex tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/pipehex/

## Install / run

```bash
git clone https://github.com/theworker02/pipehex.git
cd pipehex
node src/cli.js
node --test
```
